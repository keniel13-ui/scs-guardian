# Entry package contract — 2026-10-22

Scope: portable public candidate for Keniel's Hermes Guardian, plus private article and demo preparation. No live install, scheduler edits, paid model calls, publishing, credential reads, or outbound messages.

Provenance: the Hermes integration, soul, discipline skill and installed nightly script ALREADY EXIST. This is not contract-before-code provenance for those artifacts. This contract precedes the new portable collector and its tests only. Existing script is retained privately by hash.

Public candidate behavior:
1. Explicit owner/config; public owned non-fork repositories only. GET requests to api.github.com; no redirect credential forwarding; credentials loaded by code, never provided to model output.
2. Stable JSON observations retain full identifiers, PR numbers and state, collaborator permissions, workflow paths and SHAs, and latest per-workflow Actions runs on current default-branch HEAD. Not a universal CI/security verdict.
3. Pagination follows bounded same-origin Link URLs. A page limit or inaccessible endpoint is a failure, never an empty successful result. Workflow-directory 404 is explicitly ambiguous absent-or-unavailable.
4. Collector failure exits nonzero, prints no partial snapshot, records an error receipt where possible. Receipt-write failure is visible. Caller must not promote failed scans to baseline.
5. No arbitrary strings/timestamps generated by the collector in its fingerprint. Source event timestamps/IDs may be retained. Optional canonical board hash and age bucket; no new rules for Guardian speech.
6. Offline tests must demonstrate: same author/new PR changes snapshot; one green workflow does not hide another red workflow; access failure does not become no collaborators; page-limit failure; stable same input; private repo excluded; credential redirection refused.
7. Offline demo is labelled synthetic and shows baseline/unchanged/change/failure. It is not an LLM run or autonomy proof.
8. Readme documents same-user credential exposure, sampled history, changes between polls, API costs vs model costs, baseline behavior, and conditional skill retrieval. No live shipping claim.
